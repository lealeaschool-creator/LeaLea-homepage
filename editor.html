LESSON & SCHEDULE EDITOR

毎月のレッスンを、かんたんに。

入力した内容から更新用ファイルを作れます。空欄はサイトで「詳細準備中」と表示されます。

更新の手順

  1. 開催月・レッスン情報を入力します。未確定の項目は空欄のままで大丈夫です。
  2. 「更新ファイルを保存」で lessons.json を保存します。
  3. GitHubのリポジトリで Add file → Upload files から同じ名前でアップロードします。写真は assets フォルダーにアップロードしてください。

この画面にはログインやGitHubへの自動保存機能はありません。作業内容はブラウザを閉じると失われるため、途中でも更新ファイルを保存してください。写真の選択はファイル名の入力を補助するもので、画像自体は保存しません。

「予約受付中」を有効にし、公式LINEのURLを設定したレッスンだけ予約ボタンが有効になります。必ず正式な募集内容を確認してから有効にしてください。
