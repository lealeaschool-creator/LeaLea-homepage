LESSON & SCHEDULE EDITOR

毎月のレッスンを、かんたんに。

空欄は「詳細準備中」に。同じブラウザで、続きから編集できます。

入力 → 確認 → GitHubへ

  1. 会場を登録し、イベントの日時・料金・受付状態を入力。
  2. 「プレビューで確認」で実際の一覧を確認。
  3. 「更新ファイルを保存」で lessons.json をPCに保存。
  4. GitHubの作業ブランチのルートで Add file → Upload files から lessons.json を置き換え。PRで確認します。

写真をこの画面で選ぶと、写真も更新ファイルに含まれます（1枚800KBまで、原画像を加工せず保存）。アップロード済み写真も指定できます。GitHubへ自動送信はしません。

自動保存は、この端末・ブラウザ・同じアドレス専用です。別の端末へ移す場合や、ブラウザのデータ削除に備えて、更新ファイルも保存してください。プライベートブラウズでは終了時に消えることがあります。

1. 会場を管理

会場を選ぶとイベントに写真が反映されます。会場の削除はイベントの削除にはなりません。

2. イベントを編集

終了・非表示のイベントもここに残ります。「複製して再利用」で次のイベントを作れます。

「受付中」で公式LINEを設定したイベントだけ予約ボタンが有効です。保存したファイルをGitHubで置き換えるまでサイトは変わりません。

3. 一覧のプレビュー

サイトと同じ表示ルールです。非表示・終了したイベントは設定に応じて掲載されません。
