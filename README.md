# LeaLea ホームページ — 確認用サンプル

ベビーマッサージ教室 LeaLea の日本語・スマートフォン対応サイトです。フレームワークやビルド工程は不要です。一般公開・外部サービスへのデプロイは行っていません。

## 自分のブラウザで確認（一般公開不要）

このリポジトリをGitで取得し、フォルダー内でローカルサーバーを起動します。

```sh
git clone https://github.com/lealeaschool-creator/LeaLea-homepage.git
cd LeaLea-homepage
python3 -m http.server 3000 --bind 127.0.0.1
```

ご自身のPCのブラウザで `http://127.0.0.1:3000` を開いてください。サーバーはそのPCからのみアクセスできます。終了は `Ctrl+C` です。Windowsで `python3` がない場合は `py` または `python` を使用してください。

PRの確認時は、クローン後にPRのブランチをチェックアウトしてください。ファイル一式を同じ構成に保ち、`index.html` を直接ブラウザで開くこともできます。Pythonサーバーを使う方法を推奨します。

GitHub Pagesの有効化、一般公開、外部デプロイの設定は含めていません。ZIPのダウンロードは不要です。

## 更新する場所

- **レッスン・日程・会場・対象月齢・参加費・レッスン予約用LINE**: `editor.html` のフォームで編集 → `lessons.json` を保存してGitHubにアップロード
- **会場写真**: 編集画面で写真を選択して更新ファイルに含める。大きな画像は `assets` にアップロードし、保存済みの写真の場所を指定
- **公式LINE・Instagram**: `content.js` の `social` に確定したHTTPS URLを設定。未設定の場合は移動・送信できません。
- **よくある質問**: `content.js` の `faqs`
- **写真**: `assets/baby.png` を正式素材に差し替え、画像の説明と「SAMPLE IMAGE」表記を更新
- **講師写真**: `assets/kana-misawa.jpg`（ご提供の元写真を加工せず使用）
- **講師プロフィール・本文**: `index.html`
- **色・書体・レイアウト**: `style.css`

料金、日程、場所、対象月齢、所要時間、キャンセル規定は未提供のため準備中です。講師名・スクール名はご提供の情報を使用し、詳しい経歴は創作していません。FAQは未確定情報を案内するサンプルです。トップ・教室紹介の赤ちゃん写真はAI生成の仮素材で、実際の教室・参加者を写したものではありません。講師紹介にはご提供の写真を使用しています。顔・体型・色調・背景の加工や画像の切り抜きは行っていません。

Google Fontsはネットワークに接続できる場合に使用され、接続できない場合は端末の日本語フォントに切り替わります。公開前に、正式素材・掲載内容・SNSリンク・予約規定・必要な個人情報の取り扱い案内をご確認ください。

## 毎月の更新（コード編集は不要）

### 最初に開く

最新の作業ブランチのファイルをPCに用意し、上記のローカルサーバーを起動します。ブラウザで `http://127.0.0.1:3000/editor.html` を開きます。サイト・編集画面は一般公開する必要がありません。

### 入力とプレビュー

1. **会場を管理**で会場の追加・名前の変更・削除ができます。種類は「スタジオ」「カフェ」「結婚式場イベント」から選びます。THE KAWABUN NAGOYAとTHE NANZAN HOUSEは会場の選択肢として登録済みです。開催情報や料金は登録していません。
2. **イベントを追加**して、種類・会場・開催日・時間・参加費・対象月齢・持ち物を入力します。未確定は空欄のままにすると「詳細準備中」と表示されます。
3. **受付状態**を「受付中」「満席」「受付終了」「詳細準備中」から選びます。公式LINEのURLを設定した「受付中」のイベントだけ予約ボタンが有効です。
4. **非表示**を選ぶと、記録を残して掲載を止められます。「終了日が過ぎたイベントを自動で非表示」を有効にすると、日本時間の開催日の翌日から非表示になります。日付が未確定のイベントは自動では隠しません。
5. **複製して再利用**は、会場・時間・料金・月齢・持ち物をコピーします。開催日は空欄、受付状態は「詳細準備中」、表示設定は非表示解除に戻るので、新しい開催日を入力してください。元のイベントはそのまま残ります。
6. **プレビューで確認**でサイトと同じ一覧を確認します。編集内容はプレビューにも反映されます。非表示・過去イベントは編集フォームには残ります。

会場を削除してもイベントは削除されません。関連イベントの会場は未選択に戻るので、新しい会場を選んでください。会場名・会場写真の変更は、その会場を選んだイベントにまとめて反映されます。

### 写真の変更

「会場写真を選ぶ」でJPEG・PNG・WebPを選択します。1枚800KB以下、写真を含む全データは約3MB以下です。顔・体型・色・元の画像ファイルは加工しません。写真はブラウザの下書きと更新ファイルに含まれるので、画像の別アップロードは不要です。イベントカードは横長の表示枠に合わせて表示します。

大きな写真はGitHubの `assets` フォルダーにアップロードし、「GitHubに保存済みの写真」に `assets/半角英数字の名前.jpg` を入力します。その場合は画像もGitHubに保存する必要があります。「写真を外す」で準備中の表示に戻せます。トップ・講師写真はこの編集画面から変更できません。

### ブラウザを閉じても続きから

入力するたびにこの端末のブラウザに自動保存します。翌日も同じ端末・ブラウザ・同じアドレス（ポートも同じ）で開けば、自動保存した下書きから再開します。未確定のURLなど入力途中の文字も下書きに残ります。

ブラウザの保存容量不足・保存禁止時は警告を表示します。警告が出たら閉じる前に更新ファイルを保存してください。プライベートブラウズ、ブラウザのデータ削除、端末の変更では保存が失われる場合があります。自動保存とは別に、更新ファイルをバックアップとして保存することをおすすめします。

別のPCやブラウザでは「保存済み情報を読み込む」からバックアップのJSONを選びます。「サイトの保存済み情報に戻す」は確認後に下書きを破棄し、GitHubから取得したファイルの内容に戻します。既存の旧形式JSONも読み込めます。旧開催日時はそのまま残りますが、日付欄への入力し直しが必要です。

### GitHubへ反映する

1. **更新ファイルを保存**を押してPCへJSONを保存します。ファイル名は必ず **lessons.json** にします。ブラウザが `lessons (1).json` などに変えた場合は名前を戻してください。
2. GitHubの **LeaLea-homepage** を開き、更新する作業ブランチを選びます。新しい更新ではmainから新しいブランチを作ると、差分をPRで確認できます。
3. リポジトリのルート（README.mdやindex.htmlが並ぶ場所）で **Add file → Upload files** を選び、**lessons.json** をアップロードします。`assets` フォルダーへ入れないでください。
4. 変更内容の説明を入力し、その作業ブランチに保存します。
5. **Compare & pull request** でmainへのPRを作成し、内容を確認します。一般公開・GitHub Pagesの有効化は不要です。
6. PCにもそのブランチの最新ファイルを取得し、サイトを再読み込みして確認します。編集画面に古い下書きがある場合は、バックアップを保存してから「サイトの保存済み情報に戻す」を選びます。

この編集画面はローカルで更新用ファイルを作るためのツールです。認証付き管理画面やGitHubへの自動保存・自動反映ではありません。ブラウザへの自動保存やJSON保存だけではGitHubのファイルは変わりません。日程・料金など架空のイベント情報は登録していません。
