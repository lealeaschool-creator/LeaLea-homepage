# LeaLea ホームページ — 確認用サンプル

ベビーマッサージ教室 LeaLea の日本語・スマートフォン対応サイトです。フレームワークやビルド工程は不要です。一般公開・外部サービスへのデプロイは行っていません。

## 自分のブラウザで確認（一般公開不要）

このリポジトリをGitで取得し、フォルダー内でローカルサーバーを起動します。

```sh
git clone https://github.com/lealeaschool-creator/LeaLea-homepage.git
cd LeaLea-homepage
python3 -m http.server 3000 --bind 127.0.0.1
```

ご自身のPCのブラウザで `http://127.0.0.1:3000` を開いてください。サーバーはそのPCからのみアクセスできます。終了は `Ctrl+C` です。Windowsで `python3` がない場合は `py` または `python` を使用してください。

PRの確認時は、クローン後にPRのブランチをチェックアウトしてください。ファイル一式を同じ構成に保ち、`index.html` を直接ブラウザで開くこともできます。Pythonサーバーを使う方法を推奨します。

GitHub Pagesの有効化、一般公開、外部デプロイの設定は含めていません。ZIPのダウンロードは不要です。

## 更新する場所

- **レッスン・日程・会場・対象月齢・参加費・レッスン予約用LINE**: `editor.html` のフォームで編集 → `lessons.json` を保存してGitHubにアップロード
- **レッスン写真**: `assets` に写真をアップロードし、編集画面でそのファイル名を指定
- **公式LINE・Instagram**: `content.js` の `social` に確定したHTTPS URLを設定。未設定の場合は移動・送信できません。
- **よくある質問**: `content.js` の `faqs`
- **写真**: `assets/baby.png` を正式素材に差し替え、画像の説明と「SAMPLE IMAGE」表記を更新
- **講師写真**: `assets/kana-misawa.jpg`（ご提供の元写真を加工せず使用）
- **講師プロフィール・本文**: `index.html`
- **色・書体・レイアウト**: `style.css`

料金、日程、場所、対象月齢、所要時間、キャンセル規定は未提供のため準備中です。講師名・スクール名はご提供の情報を使用し、詳しい経歴は創作していません。FAQは未確定情報を案内するサンプルです。トップ・教室紹介の赤ちゃん写真はAI生成の仮素材で、実際の教室・参加者を写したものではありません。講師紹介にはご提供の写真を使用しています。顔・体型・色調・背景の加工や画像の切り抜きは行っていません。

Google Fontsはネットワークに接続できる場合に使用され、接続できない場合は端末の日本語フォントに切り替わります。公開前に、正式素材・掲載内容・SNSリンク・予約規定・必要な個人情報の取り扱い案内をご確認ください。

## 毎月の更新（コード編集は不要）

1. 最新の作業ブランチのファイルをPCに用意し、上記のローカルサーバーを起動します。
2. PCのブラウザで `http://127.0.0.1:3000/editor.html` を開きます。既存の `lessons.json` が自動で読み込まれます。
3. 掲載月を入力し、「レッスンを追加」で会場名・日時・対象月齢・参加費を入力します。空欄はサイトで「詳細準備中」になります。会場名が同じレッスンは自動でまとめられます。
4. 写真は `assets/半角英数字のファイル名.jpg` の形式で指定します。「写真ファイルを選ぶ」は名前入力の補助です。画像そのものはGitHubの `assets` フォルダーにアップロードしてください。JPG/JPEG/PNG/WebP対応。写真がない場合は準備中の画像を表示します。
5. 公式LINEのURLが確定したら入力します。`https://line.me/…` または `https://lin.ee/…` が利用できます。「予約受付中」を有効にしたレッスンのみ公式LINEへの予約ボタンが有効になります。空のレッスン一覧は予約を受け付けません。
6. 「更新ファイルを保存」でPCに **lessons.json** を保存します。ブラウザが `lessons (1).json` などに変えた場合は、**lessons.json** に戻してください。
7. GitHubの作業ブランチのルートで **Add file → Upload files** から **lessons.json** をアップロードして置き換えます。必要ならPRを作成して確認してください。サイトの一般公開は不要です。
8. サイトを再読み込みして内容を確認します。編集フォームは自動保存されません。途中の入力を残すには更新ファイルを保存してください。

`editor.html` はPC上で直接開くこともできます。その場合、自動読込ができなければ「保存済み情報を読み込む」で現在の `lessons.json` を選択します。サイト表示はローカルサーバーを使って確認してください。

この編集画面はローカルで更新用ファイルを作るためのツールです。認証付きの管理画面やGitHubへの自動保存機能ではありません。入力だけではリポジトリは変わりません。架空の開催情報は保存しておらず、初期状態のレッスン一覧は空です。
