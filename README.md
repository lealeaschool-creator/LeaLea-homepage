# LeaLea ホームページ — 確認用サンプル

ベビーマッサージ教室 LeaLea の日本語・スマートフォン対応サイトです。フレームワークやビルド工程は不要です。一般公開・外部サービスへのデプロイは行っていません。

## 自分のブラウザで確認（一般公開不要）

このリポジトリをGitで取得し、フォルダー内でローカルサーバーを起動します。

```sh
git clone https://github.com/lealeaschool-creator/LeaLea-homepage.git
cd LeaLea-homepage
python3 -m http.server 3000 --bind 127.0.0.1
```

ご自身のPCのブラウザで `http://127.0.0.1:3000` を開いてください。サーバーはそのPCからのみアクセスできます。終了は `Ctrl+C` です。Windowsで `python3` がない場合は `py` または `python` を使用してください。

PRの確認時は、クローン後にPRのブランチをチェックアウトしてください。ファイル一式を同じ構成に保ち、`index.html` を直接ブラウザで開くこともできます。Pythonサーバーを使う方法を推奨します。

GitHub Pagesの有効化、一般公開、外部デプロイの設定は含めていません。ZIPのダウンロードは不要です。

## 更新する場所

- **料金・対象・時間・会場・持ちもの**: `content.js` の `lesson`
- **開催日程**: `content.js` の `schedules` に開催情報を追加（ファイル冒頭に形式の例があります）
- **公式LINE・Instagram**: `content.js` の `social` に確定したHTTPS URLを設定。未設定の場合は移動・送信できません。
- **よくある質問**: `content.js` の `faqs`
- **写真**: `assets/baby.png` を正式素材に差し替え、画像の説明と「SAMPLE IMAGE」表記を更新
- **講師写真**: `assets/kana-misawa.jpg`（ご提供の元写真を加工せず使用）
- **講師プロフィール・本文**: `index.html`
- **色・書体・レイアウト**: `style.css`

料金、日程、場所、対象月齢、所要時間、キャンセル規定は未提供のため準備中です。講師名・スクール名はご提供の情報を使用し、詳しい経歴は創作していません。FAQは未確定情報を案内するサンプルです。トップ・教室紹介の赤ちゃん写真はAI生成の仮素材で、実際の教室・参加者を写したものではありません。講師紹介にはご提供の写真を使用しています。顔・体型・色調・背景の加工や画像の切り抜きは行っていません。

Google Fontsはネットワークに接続できる場合に使用され、接続できない場合は端末の日本語フォントに切り替わります。公開前に、正式素材・掲載内容・SNSリンク・予約規定・必要な個人情報の取り扱い案内をご確認ください。
